# RoobLeague

RoobLeague is a SwiftUI foundation for a polished broomball league companion app aimed at App Store release on iPhone and iPad.

## Product Shape

- Multi-role experience for players, captains, and organizers.
- League overview, standings, matchday flow, teams, calendar, and profile foundations.
- Visual system designed to look deliberate in screenshots and light in day-to-day use.

## Next Product Layers

- Authentication and onboarding
- Backend API integration
- Push notifications and live activities
- Match administration workflows
- Payments, memberships, and registration
- Accessibility, localization, and analytics
